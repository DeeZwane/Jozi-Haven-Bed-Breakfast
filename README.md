# Jozi Haven B&B: Static Website
 
Static HTML/CSS site for the fictional Jozi Haven Bed & Breakfast (Johannesburg), hosted on Amazon S3.
Part of the PRAESIGNIS AWS re/START Special Projects
 
## Structure
 
```
index.html          Home: rooms, guest services, location, contact
booking.html        Booking request form
confirmation.html   Shows the submitted booking details
error.html          404 page
css/style.css       All styling
js/                 Empty. Add JavaScript here later
images/             Room and hero photos (.jpg, lowercase, no spaces)
```
